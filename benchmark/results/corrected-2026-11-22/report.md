## 盲评一致性

Astra 两个独立盲读在全部答卷上一致 212/216（98.1%），Cohen κ = 0.857。新第二轮一致 35/36（97.2%），κ = 0.893。分歧交第三次盲读裁决。

Astra 最终裁决与 Qwen3-8B 在全部答卷上一致 200/216（92.6%），κ = 0.000。新第二轮一致 30/36（83.3%），κ = 0.000。

Qwen 按原名单重读 12/12，其中 2 份使用新答卷，其余沿用原重读。四个锚题重新盲评，判对 3/4。同家族 Astra 同时生成和评分，跨家族结果及锚题限制了对版本优劣的推断。本报告没有纳入人工判定。

版本、裁判和原始材料可以用 corrected_report.py 离线核验。完整模型可见首轮作为历史消息恢复，原线程的隐含状态无法复原。单轮答卷和首轮的生成均沿用原件。受控 API 回放单独计量，Codex 质量复测的时长和 token 不参与该项计费。
